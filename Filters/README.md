# Built-in blocking filters

On the Mac, ad blocking is uBlock Origin (Engine/ublock.json pins the release), with its own default lists, which it keeps up to date itself, except its tracker lists (EasyPrivacy and uBlock filters – Privacy), which start off: Rise blocks ads, not trackers. uBlock Origin's dashboard can turn them on. Its license is GPL-3.0; see LICENSES/GPL-3.0.txt and THIRD_PARTY_NOTICES.md.

The iPhone app's WebKit rules are in iOS/: lists from the EasyList authors (https://easylist.to/) and AdGuard, licensed under GPL-3.0; see LICENSES/GPL-3.0.txt. EasyList also offers CC-BY-SA 3.0 as an alternative: https://easylist.to/pages/licence.html. The iPhone has no separate tracker-blocking list or control.
