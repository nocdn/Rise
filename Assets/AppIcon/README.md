# Shared app icon

`Light.png` and `Dark.png` preserve the supplied 1254 × 1254 artwork unchanged.
`Dark.png` is copied byte-for-byte from Downloads' `dark.PNG`. Both apps use
`Rise.icon`, the shared Icon Composer document containing 1024 × 1024 derivatives
with matching names. The system applies its own platform mask. Liquid Glass effects
are disabled on the artwork to preserve the supplied design.

The Light layer is visible by default and hidden in the Dark appearance; the Dark
layer does the reverse using Icon Composer's appearance-specific opacity settings.
iOS and macOS select the dark artwork through their system icon appearance controls,
including Automatic when the system switches to dark appearance. Other appearances
remain generated by Icon Composer, and older systems use the
compiled default fallback icon. No runtime alternate-icon switching is required.

To regenerate the document's images from the originals, from the repository root:

```sh
sips -z 1024 1024 Assets/AppIcon/Light.png --out Assets/AppIcon/Rise.icon/Assets/Light.png
sips -z 1024 1024 Assets/AppIcon/Dark.png --out Assets/AppIcon/Rise.icon/Assets/Dark.png
```

Xcode and `scripts/build.sh` compile the same document, including platform-specific
appearances and fallback icons for older operating systems. See Apple's
[app icon guidance](https://developer.apple.com/design/human-interface-guidelines/app-icons)
and [Icon Composer documentation](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer).
