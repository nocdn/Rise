# Rise

A native macOS browser written in **AppKit + WKWebView**, with Arc-inspired chrome matched to the supplied Retina screenshots. No SwiftUI, Electron, or external dependencies. Requires macOS 14 or later.

## Build and run

```sh
./scripts/build.sh
```

The signed local app is `build/Rise.app`. Double-click it in Finder, or run `./scripts/restart.sh` to rebuild and relaunch a running copy. Local builds are signed with your Apple Development certificate when one is installed (ad-hoc otherwise), so macOS remembers folder permissions such as Downloads access across rebuilds. For development, open `Package.swift` in Xcode or use `swift build`. Run checks with `swift test`.

Website passkeys use WebKit's native WebAuthn flow, but enabling it for arbitrary
sites requires Apple's approved browser entitlement and a matching provisioning
profile. The standard local build does not enable that restricted capability.
See [Passkey approval and signing setup](docs/Passkeys.md) for Rise's request details
and the `RISE_SIGNING_IDENTITY` / `RISE_PROVISIONING_PROFILE` build options.
Run `python3 scripts/test-passkey-signing.py` to verify the profile eligibility checks.

## Implemented

- 228-point resizable sidebar; system-owned Liquid Glass traffic lights aligned with the native titlebar navigation controls. The buttons use their normal native appearance and close/minimize/fullscreen behavior, with no hover color treatment. The page matches the measured Dia frame with a 6-point outer inset, 9.5-point continuous corners with corner smoothing, and a tight shadow (14% black, 2-point blur, 1-point downward offset). The native clip, explicit shadow, and swipe snapshot masks share the smoothed contour.
- Neutral gray and rose themes, sampled from the reference screenshots; distinct selected and hovered tabs, with a soft selection shadow.
- Dark mode, selectable from the bottom paint-roller menu, uses Dia’s sampled sidebar gradient (`#363636` → `#2B2B2B`), selected tabs (`#1E1E1E`), and text colors. Address pills, popup/hover surfaces, and accents are matching extrapolations. Native controls and websites supporting `prefers-color-scheme` receive the dark appearance; the chosen theme persists across launches.
- Dia-style 34-point tab rows with 3-point gaps, 11-point continuous rounded corners with corner smoothing, and 13-point system titles with normal AppKit font rendering. Light mode uses the sampled sidebar gradient (`#DFDFDF` → `#E5E5E5`), near-white selected fill (`#FAFAFA`), and translucent white hover fill. Centered selection shadows use a 16-point blur and 12% black opacity (15% white in dark mode). Two-line developer tabs scale to 37 points, or 44 points in split groups, retaining their title/subtitle spacing and construction border. Long titles and addresses fade at the right edge instead of ending in an ellipsis.
- Sidebar closes and opens instantly with ⌘B (⌘S remains an alias). Closing hides the toolbar and native window controls, leaving the page inside a uniform 6-point inset. New Tab shares the regular tabs’ 34-point height, full row width, 3-point gap, title alignment, and continuous rounded hover background.
- Control-Tab switches in recently visited order. Releasing Control within 120 ms commits without showing UI; holding it longer reveals a centered preview switcher with favicons, titles, and cached WebKit screenshots. Control-Shift-Tab cycles backward; releasing Control or clicking a card commits, and Escape cancels. The frozen order stays stable during a gesture, with horizontal scrolling for many tabs. Unvisited restored tabs show a placeholder until a preview is captured.
- Loading/reloading fills each sidebar tab with a soft animated background, smooths progress changes, gently pulses while waiting near completion, and fades away when finished. No progress strip over the page.
- Hovered link destinations appear in a small pill at the page’s lower-left corner, including in Peek and split views. A stationary pill with a single 650 ms text shimmer signals a successfully completed preload, including sites that require cache revalidation; failed responses never trigger it. The signal confirms fetching finished, while click speed still depends on the site’s caching. Reduce Motion disables the shimmer.
- Sidebar tabs with page titles and same-origin favicons, 16-point icons with Dia-matched 4-point continuous rounding (scaled consistently in search suggestions and the tab switcher, without modifying cached image data), an approximately 8-point visible icon/title gap, and 6-point sidebar insets. Close buttons have a subtle hover background in every theme. Middle-click and release on a tab (including either split half) to close it without first selecting it. Close, duplicate, pin, and restore recently closed tabs.
- Address popup for URLs, Google searches, existing tabs, browsing-history suggestions, and browser actions. The Command-T new-tab/search popup is 400 points wide; editing the current tab's address uses the compact 350-point popup. Suggestions show real, untinted favicons from open tabs, a persistent origin-scoped cache, or each site's icon. Typed site addresses fetch their favicon after a 250 ms debounce, reuse cached/open-tab icons immediately, and cancel pending discovery when the origin changes or the popup closes. Search phrases and incomplete hosts do not fetch icons. The site's `/favicon.ico` is tried first; HTML responses or missing icons fall back to declared raster icons in bounded origin-root metadata (including CDN links). Redirected landing pages without a declared icon fall back to that destination’s `/favicon.ico`. Typed paths and query strings are not sent by icon discovery, and typing does not record a history visit. Loaded pages also supply their declared icons. Arriving icons update in place without changing selection or typed text.
- Browsing history persists locally across relaunches, with up to 2,000 successfully visited HTTP(S) URLs. Address suggestions rank literal prefixes first, then title matches, using visit frequency and recency within each tier. Typing a known URL prefix selects an inline completed suffix; continuing to type replaces it, Backspace removes it without immediately completing again, and arrow keys choose other suggestions. Search phrases and edits in the middle of an address are not completed. Clear saved visits/autocomplete through **History → Clear Browsing History…** or **URL-bar settings → ⋯ → Clear Browsing History…**. Open tabs and website cookies stay; hovering/prefetching alone does not create a visit. History ranking and matching happen entirely on the device; no suggestion service receives the query.
- URL pill moved slightly lower beneath the titlebar; its popup opens and closes instantly while keeping its soft native shadow and size. Placeholder and entered addresses share the same font; suggestion titles are vertically centered with their icons.
- Two-finger history gestures animate the existing toolbar arrow and gently compress the inset page, replacing WebKit’s full-page slide. Swipe right for back or left for forward; at 120 points the arrow turns `#007AFF` blue and requests one Generic haptic, then navigates when you lift while still beyond the threshold. Reversing below 120 points removes the blue highlight and cancels navigation; moving past the origin does not switch direction. There is at most one haptic per gesture, including if you cross the threshold again. Arrow compression, increasing resistance past threshold, and release spring (stiffness 600, damping 30) follow the supplied trackpad demo, with more visible arrowhead shortening at toolbar scale. A reversed swipe that reached the threshold still bounces home without navigating; an earlier arrow release returns over 160 ms. Vertical scrolling, horizontal page scrollers, and iframe scrolling remain with WebKit. Momentum never adds travel or extra navigations; any first momentum event can finish an owned gesture if the system omits finger-up or momentum-began. The bounded DOM probe tolerates short busy-page delays, and late outgoing snapshots can join a quick-release ripple. Toolbar Back/Forward clicks and ⌘[ / ⌘] cancel existing swipe effects and navigate directly through WebKit, with no page compression, ripple or arrow spring. Cancelling or switching tabs cancels the swipe.
- The page compression uses AppKit + Metal: stronger `distance / (distance + 160)` resistance, at most 5% page-width compression, a straight dragged edge at every height, a fixed opposite edge, matching horizontal content compression, and a 550 ms spring return (stiffness 500, damping 38, tiny overshoot, exact flat endpoint). The Gaussian ripple starts immediately on finger-up, lasts 300 ms, and reveals the actual history destination behind a wider, full-height wavefront moving in from the released side. Horizontal displacement tapers linearly toward the opposite edge without vertical shear. The release ripple keeps the demo’s highlight, attenuation, strength and edge origin, with a wider envelope and faster travel; forward navigation mirrors the effect. The page’s outer fill, edge and shadow compress with its content on both sides; browser chrome and arrow positions remain fixed. Early/reversed releases ripple back to the current page; system cancellation returns without a ripple. Full-resolution history previews are bounded to eight images/64 MB and replaced by the live destination after first paint. Uncached destinations reveal as WebKit supplies their first snapshot. Reduce Motion keeps the live page flat. Run `python3 scripts/test-cloth-live.py` for a native-window regression covering both directions, reversal, cancellation, interruptions, missing finger-up, fixed chrome, the visible Metal surface, and Reduce Motion.
- Separate WebKit instances per tab, shared persistent website data, back/forward history, reload/stop, trackpad navigation, zoom, and Find on Page.
- Built-in **Block Ads & Trackers**, enabled by default. Uncheck or recheck it in the URL-bar settings to reload the current page with the new policy. The preference persists and applies across tabs, split panes, Peek, popups, and speculative link preloads. Hidden loaded tabs refresh when next opened. Native WebKit content rules block network requests and hide ad elements before browsing starts; they use bundled EasyList, EasyPrivacy, and HaGeZi Multi PRO mini snapshots. No extension installation is required.
- New-window links open in tabs. Command-click opens a tab; Shift-click (or Option-click) opens Peek.
- Optional **Preload Links (Experimental)** in the URL-bar site controls. Hovering over an HTTP(S) link for 150 ms warms the page and its static resources in WebKit’s shared cache, without running page scripts or adding a tab/history entry. Short hovers, downloads, and same-page anchors are skipped. The preference persists and defaults to off. Preloads are limited to two at a time and 32 distinct URLs per minute; switching off cancels pending loads. Cacheable pages open faster; sites that disable caching or depend on JavaScript still load normally. Enabling this uses additional bandwidth and contacts hovered destinations before clicking.
- Peek overlay with close, expand-to-tab, and split controls; two-page split view. Like Arc, a Shift-clicked link springs into the Peek card with a subtle overshoot, carrying an enlarged snapshot of the link that hands over to the live Peek page within about 100 ms while the card is still growing; its shadow fades in along the way. With the same spring, the page behind recedes to 98.2% about its center as it dims; the dimming lives inside the page, so it recedes with it and never covers the page’s shadow. Holding Shift (or Option) over a link for 80 ms starts rendering its page invisibly at Peek size, so the click shows it from the first frame; an unused standby page is discarded after 20 seconds or when another link is targeted. Escape, the close button or clicking outside quickly springs the page back into the link with a barely visible bounce while the page behind springs back to full size, overshooting by about 1 point per side, crossfading into the link itself (relocated if the page scrolled). The motion is interruptible: dismissing a Peek that is still growing reverses it from wherever it is, and a new Peek can open while the previous one is still shrinking. Peeks without a visible source link scale gently from the center; Reduce Motion shows and hides Peek instantly. Run `python3 scripts/test-peek-live.py` to verify the motion in a native window. Split pairs occupy one sidebar row with two compact favicon/title sections: a divider when inactive, and a softly shadowed rounded container with inset highlights when selected. Clicking either half or page focuses that pane without swapping left/right. Groups remain together when switching tabs and across relaunches; right-click a half to separate the pair. Closing one half leaves the other as a normal tab.
- Tabs can be dragged vertically to reorder without replacing their WebKit view, favicon, loading state, size or styling. Split pairs move as one row; each neighbor crossing requests a subtle alignment haptic. Neighbor rows and the selected shadow move together over 180 ms. Holding near the list edges autoscrolls while keeping the dragged row fully visible; Escape cancels the drag. Tab order is saved, including the positions of pinned tabs.
- New and reopened tabs appear immediately at the top; existing rows make space together. Closing a tab moves the remaining rows upward together with the same quick transition. Double-click a title to edit it in place with the full text selected, unchanged typography and padding: Enter saves immediately and Escape discards. Custom names survive navigation, reloads, archiving and restarts. Pressing or holding tabs keeps their size fixed, matching Dia. Reordering, insertion and collapse retain the quick 180 ms transition; Reduce Motion removes that motion. Run `python3 scripts/test-tab-organization-live.py` to verify real AppKit event routing, live layer motion and inline editing.
- Copy the current page link with **⌘⇧C** or the URL-bar link button. A native sideways popover confirms “Link copied”, with AppKit’s material and opening/closing animation; its share button opens AirDrop directly for that copied URL. It dismisses after 1.5 seconds, stays open while hovered, and restarts the timer when the pointer leaves. Copying with the sidebar closed restores the sidebar instantly. Copy/settings glyphs are 14 points and fade in over 140 ms while any part of the sidebar is hovered, then fade out over 120 ms unless Site Controls is open. Popovers remain anchored to the URL bar while these icons fade. Run `python3 scripts/test-copy-link-live.py` for native placement, fade and routing checks.
- Successful Copy URL actions swap the URL-bar link glyph for a “link copied” glyph that fades in while springing up from a smaller size, restoring it after one second; repeated copies restart the timer, and Reduce Motion swaps the glyph immediately. The URL pill has a distinct background; its text uses the full available width when copy/settings controls are hidden. The URL fade boundary moves inward/outward with the controls over 140/120 ms without moving or scaling the glyphs, and the controls remain visible while Site Controls is open. URL-bar Site Controls uses AppKit’s native popover material and opening/closing animation, with Share, Screenshot, OCR and More across the top. These buttons and Extensions share continuous rounded corners, a fine border and a tiny shadow, with a slightly smaller proportional size. Settings use circular status icons and live text without trailing checkmarks or hover backgrounds, with a slightly larger left inset. The footer is removed; More includes connection details, split view and permissions that do not already have a visible row. Theme selection remains in the sidebar’s bottom paint-roller menu. The Extensions tile explains the current WebKit limitation rather than claiming extension support.
- Camera, microphone, and (on macOS 27+) location requests use a native “Not Now / Allow” popover attached to the settings icon. Decisions persist per requesting origin, including its scheme and port; navigation, tab changes, and dismissal safely cancel pending requests. Notifications can be allowed or blocked per site and use macOS notifications while the page is open; background Web Push/service-worker notifications are not implemented. macOS may separately ask for system permission. Automatic Picture-In-Picture is allowed per site by default, using WebKit’s supported video presentation API when a playing video goes into the background. Run `python3 scripts/test-site-controls-live.py` to verify native light/dark popovers and the real WebKit permission-message path.
- Developer Mode: striped URL toolbar with an editable address (Enter navigates, Escape cancels), yellow/black selected-tab border, URL copy, screenshot export, JavaScript evaluation, page source, native site-information popover, and split view. Toggling it slides the toolbar and page together over 180 ms; the tab title moves upward while its URL fades in and settles downward by 2 points. Reversing a toggle continues from the current position, and Reduce Motion uses immediate changes. Localhost enables it automatically. WKWebView is inspectable from Safari's Develop menu.
- Web dialogs, file-upload panels, and visible navigation errors.
- Downloads save straight to the Downloads folder, numbered like Finder (“report 2.pdf”) when the name is taken. As each one starts, a blue download icon arcs from the pointer into the sidebar’s archive icon: it stays full size for most of the way, shrinks to about a quarter on arrival, and drops into the box as the lid tilts open and the box tips forward to catch it, then the archive recoils slightly along the direction the download came from and springs back. With the sidebar collapsed, the archive springs in on a small rounded tile in the bottom-left corner, a little lighter than the sidebar with a hairline border, catches the download, and slides away half a second after the last one lands. Clicking the archive opens a native popover listing downloads newest first, capped at five rows with scrolling for more, each with its file icon, name and size (or progress while downloading); a row highlights on hover and opens the file in its default app when clicked. Hovering a finished download also shows an eye, which previews it in Quick Look (for documents, media, text and fonts), and an X, which clears it from the list without deleting the file. An empty list says “No downloads yet”. Press ⌥⌘L to open the list (from the bottom-left corner when the sidebar is collapsed); the arrow keys then move the highlight, ignoring the pointer until it moves, and Return opens, Space previews and Delete clears the highlighted download, as they also do for a row under the pointer. Closing Quick Look with its close button, Space or Escape brings the list back with the previewed row focused and scrolled into view. The list persists across relaunches and hides files that were moved or deleted. The motion and all its values come from `Playgrounds/download-flight.html`, an interactive tuning page; unit tests check the native motion against it frame by frame, and `python3 scripts/test-download-flight-live.py` verifies it with a real WebKit download. Reduce Motion skips the animation.
- Session restoration for URLs, titles, favicons, back/forward history, selected tab, pins, theme, developer mode, and sidebar width. Each tab saves WebKit’s own session state, so after a relaunch it reopens on the page it was showing with its back and forward pages intact; inactive tabs keep their saved history until first opened. Favicons are saved as compact 32-pixel PNGs with their security origin and restored immediately for active and inactive tabs, before pages load. Invalid images are ignored, and icons cannot leak across sites, schemes or ports. Old sessions remain compatible and can populate missing icons without loading all their pages. Cookies/site storage use WebKit's persistent store. Recently closed tabs are currently session-local.

| Shortcut | Action |
| --- | --- |
| ⌘T | New-tab popup |
| ⌘L | Edit current address |
| ⌘W | Close current tab |
| ⇧⌘T | Restore last closed tab |
| ⌘[ / ⌘] | Back / forward |
| ⇧⌘[ / ⇧⌘] | Previous / next tab |

| ⌃D | Toggle developer mode |

Use the paint-roller button at the sidebar's bottom left to change theme. The archive button at the bottom right lists your downloads in a popover (click one to open it in its default app, or hover it to preview or clear it); right-click it for recently closed tabs. Sidebar icons use `#717171` (the dark theme keeps its lighter grey). Right-click a tab to pin, duplicate, split, or close it. Site controls sit beside the compact address pill.

## Scope

This is the first working browsing version, not the full Arc product. Arc account sync, Chromium extensions, multiple spaces/profiles, Boosts, AI features, and Arc's full developer-tool suite are not implemented. The developer toolbar uses native WebKit features; its action set differs from Arc's. The layout and colors follow the references, but pixel-perfect identity across macOS versions is not guaranteed.

Reference behavior: [Arc Developer Mode](https://resources.arc.net/hc/en-us/articles/20468488031511-Developer-Mode-Instant-Dev-Tools), [Arc Pinned Tabs](https://resources.arc.net/hc/en-us/articles/19231060187159-Pinned-Tabs-Tabs-you-want-to-stick-around), [Arc Command Bar](https://start.arc.net/command-bar-actions). Engine: [Apple WKWebView](https://developer.apple.com/documentation/webkit/wkwebview).

## Structure

`RiseCore` contains address resolution and persisted session data. `Rise` contains the AppKit window, sidebar, command popup, tab/webview ownership, WebKit delegates, and browser actions. `Tests` covers URL handling, disk persistence, tab lifecycle, split cleanup, restoration, and actual WebKit JavaScript execution.

Ad blocking includes a controlled HTTP regression that checks blocked requests never reach the server, normal content remains visible, static/dynamic/frame ads are blocked, and toggling reloads with the correct policy. Run `python3 scripts/test-adblock-live.py` for two repetitions each of Turtlecute and AdBlock Tester in a real Rise window. The bundled October 2, 2026 rules scored 132/132 and 100/100, respectively. Public test scores can change as their checks and filter lists evolve. Filter snapshots are refreshed for releases with `python3 scripts/update-adblock.py`; they do not update automatically at runtime. See `Filters/README.md` and `THIRD_PARTY_NOTICES.md` for sources and licenses. Native content rules do not support every extension-only scriptlet or procedural filter, so these scores do not imply every site's ads will always be blocked.

The preload text shimmer translates [ElevenLabs Shimmering Text](https://github.com/elevenlabs/ui/blob/main/apps/www/registry/elevenlabs-ui/ui/shimmering-text.tsx) to Core Animation: 250% background width, text-length-based spread, and linear text-clipped gradient motion. It runs once in 650 ms instead of the component’s two-second default. Native text rendering and glyph alpha coverage stay the same throughout; a contrasting glint sweeps through the existing strokes in every theme, without changing their weight. See `THIRD_PARTY_NOTICES.md` for the MIT attribution.
